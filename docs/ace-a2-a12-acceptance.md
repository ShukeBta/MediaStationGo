# A2–A12 功能验收清单

本清单用于验证 [A2–A12 使用说明](ace-a2-a12-guide.md) 中的行为。以下复选框是可复用的验收用例，不表示已通过。本轮已执行的自动化检查、数据库测试及浏览器操作见 [本地验证记录](ace-a2-a12-validation.md)；其中未执行项仍需在对应环境补做。

## 准备隔离的验收数据

准备管理员和受限普通用户、两套媒体库，以及电影、同剧两季、同名不同剧、双 Part、已有 NFO、STRM 和多音轨/字幕的少量样本。文件写入和删除用可丢弃的副本；STRM 指向单独的测试目录。记录应用提交、操作系统、数据库版本、FFprobe 版本与客户端版本。

分别在 SQLite 与 PostgreSQL 的测试库执行涉及持久化的步骤；不能只凭 SQLite 用例或 SQL 字符串检查判定 PostgreSQL 已通过。外部资料源可使用固定响应夹具核对逻辑，再以已配置的真实服务做少量连通检查。报告中记录使用的是夹具还是真实请求。

| A2.3 | 对可用、不可用和无法判定的代理执行检测；取消清理，再确认清理 | 检测/取消不删除；确认后只删除本次判定不可用的节点，旧检测凭证不可作用于已变化的池 |
| A3.1 | 对已匹配 TMDb 剧集更新目录，包含已收录和未收录集 | 完整季集目录出现；未收录集无播放入口、无虚假 Media/下载任务；可播放链接遵守当前库与用户权限 |
| A3.2 | 使用近期、未知日期、一年内及更早季夹具；重复保存完整/摘要快照；模拟 404 与重启 | 到期规则分别为 1/3/10/20 天；完整详情保留；404 不删除本地文件；持久化到期/租约防止重复执行 |
| A4.1 | 补全作品演职员；搜索姓名/原名/别名；打开人物及作品列表 | 头像与资料可见；同名不同 provider ID 不合并；人物和作品均遵守可见性与分页 |
| A4.2 | 翻译人物和两个作品中的角色；重复刷新；手动增删演员 | 原始资料保留、缓存按作品上下文隔离；保留未移除演员角色/译文与 crew；原名/译名不重复显示 |
| A5.1 | 长视频分别报告 59、60 秒进度，短/未知时长报告 19、20 秒；同会话重复上报 | 达门槛后同会话仅计一次；进度与统计规则一致；手动已看及自动前集标记不增加真实播放次数 |
| A5.2 | 在 UTC 日/周/月边界产生统计夹具，按用户/库/类型筛选明细与热榜 | 各数据库汇总一致，热榜按选定日/周，分页总数与明细一致 |
| A5.3 | 发起 Emby 请求，带普通播放参数及测试 Token/Cookie；查看请求日志 | 显示模板路由、状态与耗时，凭据/原始 URL/正文不落日志；筛选分页正常，首页实时刷新可暂停 |
| A6.1 | 在任务目录手动运行维护任务，再次点击同任务；查看转码/下载/字幕等既有区域 | 后台任务可跟踪，运行中同任务不重复启动，现有业务任务入口可用 |
| A6.2 | 产生跨 UTC 日期日志，分页并按任务筛选；重启时留一个运行中的测试任务 | 历史跨重启保留，旧运行项标记中断；按日数量、分页无重复漏项；日志凭据脱敏 |
| A7.1 | 单项探测多音轨/字幕样本，再重启、重扫含简略技术字段的 NFO | 完整轨道可再次读取，技术字段不被简略 NFO 降级；变化的来源不继续使用旧探测文档 |
| A7.2 | 配置重叠 URL 映射、不可用文件、`..` 路径和越界符号链接；执行批量回填 | 最长合法前缀优先；不可用映射可回退远程探测；越界不读取；回填任务可见且受并发限制 |
| A8.1 | 预览测试 STRM 指向的文件，取消后再确认删除 | 取消不改变文件；确认仅删除预览目标，保留 STRM 与媒体库记录 |
| A8.2 | 尝试目录删除、根目录、包含 STRM 的父目录、越界链接，以及预览后改动目标 | 整目录需额外选择和确认；根/越界/引用所在父目录不允许；目标变化要求重新预览 |
| A9.1 | 调整 Emby 库排序、移至顶部、隐藏，使用受限用户刷新客户端 | 展示顺序保存，隐藏入口消失；修改展示不能扩大受限用户访问权限 |
| A9.2 | 开关自动前集标记，完成第二季某集；包含跨库同名剧、第一季和不可见集 | 仅开启时标记同库同剧同季可访问前集，保留已有完成时间；不污染播放统计 |
| A9.3 | 扫描 `Example Part1.mkv`/`Part2.mkv`，增加/移除分段，再测试重复编号及手动分组 | 合法多 Part 自动更新；重复编号不误聚合；手动聚合/版本分组保留 |
| A10.1 | 对已有图片请求限制宽高、成对 fill、WebP/PNG/JPEG，包含 EXIF 方向和透明图片 | 比例/居中裁切正确，不放大；方向正确，透明度/JPEG 白底符合格式；旧 URL 继续可用 |
| A10.2 | 请求动画、重复/越界参数；并发请求同变体，再修改源图 | 动画原样保留；错误参数 400；相同变体复用缓存，源图变化失效；新格式与尺寸不串用缓存 |
| A11.1 | 修改电影、单集、整剧元数据，分别选中/取消 NFO 写入，重读文件与数据库 | 取消时只写数据库；选中时写正确 NFO；单集 aired 保留，整剧 ID 不写入单集 uniqueid |
| A11.2 | NFO 包含其他 thumb、旧 poster/art、ID/日期/简介别名、嵌套 rating、演员角色和自定义 XML；编辑或清空对应字段 | 未编辑字段保留；旧别名不覆盖新值；清空评分不从嵌套值恢复；无关图片、轨道、注释保留 |
| A11.3 | 使用损坏 XML、不可写文件、符号链接 NFO，或制造提交失败 | 返回错误；单次保存的数据库/演员关系回滚，文件恢复或明确报告并保留外部新写入；不越界写入 |
| A12.1 | 启动时打开任务中心并触发扫描/维护任务，完成后再试；执行关闭 | 阶段、计数、耗时可见；未 ready 返回 503；就绪后可执行；关闭取消并等待任务 |
| A12.2 | 同时手动扫描两个本地库；再自动添加多个根目录或刷新 STRM | 同时只执行一个本地扫描；手动冲突 409 且未排队，自动任务等待后继续，无目标静默丢失 |
| A12.3 | 链接目录离线/恢复，增加循环链接，移动一个非空目录进入监听根 | 离线保留媒体；恢复可继续监听；循环不无限遍历；移入子树被增量扫描 |

## 记录实际验证结果

每轮验收需附应用提交、环境、完整命令或 UI 操作、开始/结束时间、结果及脱敏日志/截图。用例未执行、因环境跳过、失败与通过应分别列明。PostgreSQL 测试未连接真实实例而被跳过时不能记为通过；线上部署和真实服务连通也不能由本地测试代替。

仓库已有单元、接口和 PostgreSQL 集成测试，可按变更范围运行。最终发布记录应引用实际运行输出，并列出尚未覆盖的客户端、平台或外部服务；本清单不预填这些结论。
